# 하루여행

하루 안에 다녀올 장소를 검색하고, 취향과 이용 시간에 맞춰 가까운 순서로 일정을 만드는 웹앱입니다.

## 현재 기능

- 카카오맵과 실제 장소 검색
- 카페·맛집·전시·산책 취향 선택
- 시작·종료 시간 기반 일정 구성
- 장소 간 거리 기반 동선 정렬
- 지도 번호 마커와 경로선 표시
- 예상 도보 이동시간 및 전체 소요시간 계산
- 브라우저에 현재 일정 저장

## 로컬 실행

1. `.env.local.example`을 참고해 `.env.local`에 카카오 JavaScript 키를 입력합니다.
2. 카카오 디벨로퍼스의 JavaScript SDK 도메인에 `http://localhost:3000`을 등록합니다.
3. 아래 명령으로 실행합니다.

```bash
npm install
npm run dev
```
