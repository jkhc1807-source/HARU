# 하루여행 제품 명세

> 일정 시간 정책: 자동 생성 일정은 선택한 시간 범위 안에 맞춘다. 사용자가 장소를 직접 추가하거나 체류시간을 바꿔 범위를 넘긴 경우에는 장소를 임의로 삭제하지 않고 초과 시간을 안내하며, `시간에 맞게 줄이기`를 선택할 수 있게 한다.

## 문제

하루 나들이를 계획할 때 장소는 쉽게 찾을 수 있지만, 제한된 시간 안에서 어떤 순서로 방문해야 하는지 결정하는 과정이 번거롭습니다.

## 목표

사용자가 지역, 이용 시간, 취향을 고르면 실제 장소를 검색하고 이동 부담이 적은 하루 일정을 빠르게 구성합니다.

## 핵심 사용자 흐름

1. 여행 지역과 시작·종료 시간을 입력한다.
2. 카페, 맛집, 전시, 산책 중 취향을 선택한다.
3. 주변 장소를 검색하거나 검색 결과를 일정에 추가한다.
4. 앱이 이용 시간 안에 들어오는 장소를 가까운 순서로 배치한다.
5. 시간표와 지도 경로를 확인하고 장소를 추가·삭제한다.

## MVP 완료 기준

- 실제 장소 검색이 동작한다.
- 선택한 시간 범위를 넘지 않는 일정을 만든다.
- 장소별 도착시간, 체류시간, 다음 이동시간을 표시한다.
- 지도에 방문 순서와 연결 경로를 표시한다.
- 새로고침 후에도 현재 일정이 유지된다.

## 계산 기준

- 거리는 위도·경도의 대략적인 km 환산값으로 계산한다.
- 예상 도보 속도는 시속 4.5km로 가정한다.
- 지도 경로선은 방문 순서를 보여주는 직선 연결선이다.
- 실제 도로 기반 경로와 대중교통 시간은 후속 단계에서 연동한다.
