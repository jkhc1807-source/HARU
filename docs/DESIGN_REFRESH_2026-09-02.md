# 하루여행 프리미엄 매거진 리프레시

## 목표

기존 초록·크림 색감과 모든 기능을 유지하면서, 화면 전체를 여행 잡지의 한 호처럼 보이게 만든다. 장식보다 사진, 타이포그래피, 여백, 명확한 행동 순서로 첫인상을 높인다.

## 유지할 것

- 카카오 장소 검색과 지도
- 일정 생성·저장·불러오기·공유·삭제
- Google 로그인과 Supabase 동기화
- 카드 드래그, 순서 변경, 시간·메모 편집
- 기존 숲 사진과 출처 표기

## 디자인 방향

- 배경: 따뜻한 종이색과 아주 옅은 초록 빛
- 핵심색: 깊은 숲색, 잎색, 작은 황토색 포인트
- 타이포: 큰 제목과 작은 영문 캡션의 대비
- 형태: 모든 요소를 둥글게 만들지 않고, 큰 장면에만 곡선을 사용
- 일정: 편집된 여행 코스처럼 번호와 연결선을 강조
- 지도: 코스의 중심 도구로 보이되 일정 패널과 같은 프레임에 결합
- 검색: 별도 부록이 아니라 다음 장소를 발견하는 두 번째 장면으로 표현

## 화면별 적용

### 첫 화면

- 사진과 큰 제목의 존재감을 강화한다.
- 계획 입력 카드는 밝고 정돈된 종이 카드처럼 만든다.
- 선택과 생성 버튼만 잎색을 사용해 행동의 우선순위를 분명히 한다.

### 일정과 지도

- 전체를 하나의 여행 작업 보드로 묶는다.
- 일정 번호, 카테고리, 시간 정보의 위계를 분리한다.
- 지도에는 작은 편집 라벨과 깊이감 있는 프레임을 적용한다.

### 장소 검색

- 짙은 초록색 인트로와 밝은 결과 영역을 대비시킨다.
- 장소 카드는 카테고리 색만 보조적으로 사용하고 내용 가독성을 우선한다.

## 반응형 원칙

- 800px 이하에서는 사진, 입력 카드, 일정, 지도를 한 열로 배치한다.
- 320px에서도 가로 넘침 없이 긴 장소명과 주소가 줄바꿈된다.
- 터치 영역은 최소 40~44px을 유지한다.
- 모션 감소 설정에서는 등장·이동 효과를 제거한다.

## 완료 조건

- 주요 기능 핸들러와 데이터 구조 변화 없음
- 자동 테스트와 빌드 통과
- 320, 375, 768, 1440px 화면 확인
- 메뉴, 입력, 드래그 관련 포커스와 클릭 영역 유지

## 마이크로 인터랙션

- Amicro의 오브젝트 반응 방식을 참고하되, 생성·메뉴·장소 추가·일정 카드·드래그·지도 연결처럼 결과가 있는 동작에만 제한한다.
- 생성 버튼은 짧은 빛과 화살표 이동, 더보기는 점에서 닫기 표시로 전환한다.
- 장소 추가 상태와 일정 카드에는 짧은 회전·들림 반응을 사용하고 터치 화면에서는 불필요한 hover 이동을 제거한다.
- 지도 연결과 성공 문구는 상태를 알아볼 수 있을 정도로만 움직인다.
- 별도 모션 라이브러리를 추가하지 않고 CSS를 사용하며 `prefers-reduced-motion`에서는 효과를 제거한다.
