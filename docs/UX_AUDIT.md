# 하루여행 v20 개선 점검

마지막 갱신: 2026-08-05

## 현재 평가

하루여행은 실제 카카오 장소 검색, 일정 생성, 지도 표시, 직접 편집까지 가능한 MVP다. 초록·라임 색상과 여행 플래너 콘셉트는 유지한다. 앞으로는 새 기능의 수보다 사용자 기대와 실제 동작을 일치시키고 모바일·접근성·코드 안정성을 높이는 데 집중한다.

## 우선순위

### P0 — 신뢰를 해치는 문제

- [x] 실제 일정 데이터 없이 주소만 복사하던 `일정 공유` 제거
- [x] 전체 일정을 한 번에 비울 수 있는 `새 일정 시작` 제공
- [x] 삭제·추가·정렬·초기화 후 `실행 취소` 제공
- [x] 직접 편집한 일정이 선택한 종료 시간을 넘으면 초과 시간 표시
- [x] 초과 일정을 현재 시간 범위에 맞게 줄이는 기능 제공
- [ ] 지역 변경 시 이전 지역 일정이 남지 않도록 일정과 지역을 함께 관리
- [ ] 지도·동선 계산이 실제 도보 길찾기가 아닌 직선거리 추정임을 더 명확히 안내

### P1 — 핵심 사용성

- [ ] 출발 지점 또는 첫 장소 고정 기능
- [ ] 장소별 체류시간 수정
- [ ] 모바일에서는 일정 목록을 지도보다 먼저 보여주거나 지도를 접을 수 있게 구성
- [ ] 드래그를 쓰지 않아도 위·아래로 순서를 변경할 수 있는 대체 조작
- [ ] 지역 자동완성의 방향키 탐색과 선택
- [ ] 검색·생성 요청 중 중복 실행 방지

### P2 — 저장과 확장

- [ ] 여러 일정에 이름을 붙여 저장
- [ ] 일정 데이터가 포함된 실제 공유 링크
- [ ] 일정 이미지 저장과 모바일 공유 시트
- [ ] 위 기능이 필요해질 때 Supabase 등 서버 저장소 검토

## 역할별 점검

### 기획

- 핵심 흐름은 `지역·시간·취향 선택 → 일정 생성 → 편집 → 지도·리뷰 확인`으로 유지한다.
- 출발 지점, 종료시간 초과, 새 일정 시작처럼 사용자가 계획을 통제하는 기능을 우선한다.
- 예약, 결제, 실시간 교통, 장기 여행은 현재 범위에 포함하지 않는다.

### 디자인

- 현재 색상과 브랜드 분위기는 유지한다.
- 9~10px 보조 글자는 읽기 쉬운 크기로 올린다.
- 일정 카드의 드래그, 리뷰, 삭제, 이동시간 정보가 서로 경쟁하지 않도록 정보 위계를 정리한다.
- 모바일의 큰 지도는 접기·펼치기 또는 일정 뒤 배치를 검토한다.
- 시간 초과와 정렬 완료 같은 중요한 상태는 색상과 문구로 분명히 알린다.
- [x] 동선 정리 결과 문구 유무와 관계없이 버튼의 수직 정렬을 유지한다.
- [x] 히어로를 압축하고 입력 카드를 둥근 플래너 패널로 강조한다.
- [x] 카테고리별 색상을 적용한 여행 티켓형 일정 카드로 개편한다.
- [x] 일정·지도를 하나의 둥근 작업 보드로 묶고 지도 요약 배지를 제공한다.
- [x] 장소 검색을 별도 카드형 섹션으로 정돈한다.

### 퍼블리싱·접근성

- 드래그 손잡이에 키보드 이동 기능 또는 대체 메뉴를 제공한다.
- 모든 버튼과 링크의 포커스 표시를 통일한다.
- 모바일 터치 영역은 최소 44px을 기준으로 점검한다.
- 긴 장소명과 주소, 320px·375px·태블릿 화면을 검증한다.
- 새 창으로 열리는 카카오맵 링크를 보조기술에도 안내한다.

### 개발

- 비대해진 `app/page.tsx`를 지도·검색, 일정 계산, 드래그, 화면 컴포넌트 단위로 분리한다.
- 로컬 저장 데이터에 버전을 부여하고 손상된 JSON을 안전하게 처리한다.
- 지역 자동완성의 오래된 비동기 응답이 최신 결과를 덮지 않게 한다.
- 일정 시간 계산과 동선 정렬에 자동 테스트를 추가한다.
- 동선 정리는 실제 도로 최단경로가 아닌 좌표 기반 추천 정렬임을 코드와 UI에서 일관되게 표현한다.

### 사용자

- 잘 되는 점: 로그인 없이 실제 장소를 찾고 지도·일정·카카오 리뷰를 한 흐름에서 볼 수 있다.
- 혼란 요소: 임의의 시작 장소, 시간 초과, 정렬 전후 차이, 지역과 저장 일정의 불일치다.
- 우선 해결할 질문: “왜 여기서 시작하지?”, “시간 안에 끝나나?”, “실수한 변경을 되돌릴 수 있나?”, “새 일정은 어떻게 시작하나?”

## 줄이거나 미룰 것

- 실제 데이터 공유가 없는 공유 버튼
- 기본 일정으로 고정되는 성수동 샘플: 추후 `샘플로 체험하기`로 분리
- 모바일에서 항상 크게 노출되는 지도
- 지나치게 작은 영문 장식 문구와 중복 안내
- 로그인, 예약, 결제, 실시간 교통정보
- 실제 공유·다중 기기 저장 전의 성급한 Supabase 도입
