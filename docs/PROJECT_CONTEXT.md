# 하루여행 프로젝트 컨텍스트

마지막 갱신: 2026-08-04

## 한 줄 설명

사용자가 지역, 이용 시간, 취향을 고르면 카카오의 실제 장소 데이터를 검색해 하루 나들이 동선을 만드는 웹앱이다.

## 현재 배포

- 서비스명: 하루여행
- 배포 주소: https://haru-trip-planner.njhina48.chatgpt.site
- 현재 배포 버전: v7
- Sites 프로젝트는 `.openai/hosting.json`의 기존 `project_id`를 계속 사용한다.
- 카카오 JavaScript SDK 도메인에 배포 주소와 로컬 개발 주소가 등록되어 있다.

## 현재 구현된 기능

- 카카오맵 표시와 장소 키워드 검색
- 지역 입력: 성수동, 연남동, 해운대, 제주 애월 등 자유 입력
- 취향 선택: 카페, 맛집, 전시, 산책
- `나만의 하루 만들기`를 누르면 `지역 + 선택 취향`으로 카카오 장소를 검색
- 검색 결과 중복 제거 후 가까운 장소 순으로 최대 6곳 구성
- 시작·종료 시간 안에서 일정 구성
- 지도 번호 마커, 직선 동선, 예상 도보시간 표시
- 장소 추가·삭제 및 현재 일정의 브라우저 로컬 저장

## 데이터 출처와 계산 방식

- 첫 화면의 성수동 장소는 초기 체험용 샘플 데이터다.
- 실제 생성과 장소 검색 결과는 카카오맵 JavaScript SDK `services.Places().keywordSearch()`에서 가져온다.
- 별도의 맛집·카페 데이터베이스나 웹 스크래핑은 사용하지 않는다.
- 도보시간은 실제 길찾기 결과가 아니다. 좌표 간 대략적인 거리와 시속 4.5km를 기준으로 추정한다.
- 지도 경로선도 실제 도로를 따르는 경로가 아니라 방문 순서를 나타내는 직선이다.

## 주요 파일

- `app/page.tsx`: 화면, 카카오 검색, 일정 생성, 지도 로직
- `app/globals.css`: 전체 디자인과 반응형 스타일
- `app/layout.tsx`: 제목, 설명, 공유 미리보기 정보
- `scripts/generate-map-config.mjs`: 빌드 시 카카오 JavaScript 키 설정 생성
- `docs/PRODUCT.md`: 제품 명세
- `docs/ROADMAP.md`: 개발 순서
- `.env.local.example`: 환경변수 이름 예시

## 환경변수와 보안

- 카카오 JavaScript 키는 `.env.local`의 예시 형식을 따른다.
- 실제 키값은 이 문서, README, 커밋 메시지에 적지 않는다.
- JavaScript 키는 브라우저에서 사용되는 공개형 키이지만, 카카오 콘솔의 허용 도메인 제한은 유지한다.
- Admin 키나 REST API 키를 프런트엔드 코드에 넣지 않는다.

## 알려진 제약과 주의점

- 지역은 현재 자동완성된 행정구역 선택이 아니라 자유 텍스트다.
- `전시`와 `산책`은 카카오의 단일 정확 카테고리가 아니므로 키워드 검색 품질에 영향을 받는다.
- 기존 일정이 로컬 저장소에 남아 있으면 첫 화면에 이전 일정이 복원될 수 있다.
- 운영시간, 휴무일, 실제 도보 경로, 대중교통 시간은 아직 반영하지 않는다.
- 현재 자동 테스트의 미리보기 스켈레톤 관련 2개 항목은 오래된 스타터 기준이라 실패한다. 앱 빌드 자체는 성공한다.

## 바로 다음에 할 만한 작업

1. 지역 검색 자동완성과 명확한 지역 선택 UI
2. 새 지역 입력 시 이전 지역 일정과 검색 결과를 자연스럽게 초기화
3. 카테고리별 검색 결과 균형 조정 및 결과가 적을 때 대체 키워드 검색
4. 장소별 체류시간 수정과 드래그 순서 변경
5. 실제 공유 링크 또는 일정 이미지 저장
6. 오래된 스타터 테스트를 현재 앱 기준으로 교체

## 최근 결정 기록

- Google Maps 유료 사용 가능성 때문에 카카오맵으로 전환했다.
- 비용을 최소화하기 위해 별도 서버 데이터베이스와 유료 길찾기 API는 사용하지 않는다.
- v7에서 지역 입력과 취향 버튼을 실제 카카오 검색에 연결했다. 이전에는 지역 제목만 바뀌고 성수 샘플 일정이 남는 문제가 있었다.
- 프론트엔드 작업 표준을 `AGENTS.md`에 추가했다. 기존 프로젝트가 일반 CSS를 사용하므로 SCSS·Tailwind를 새로 강제하지 않으며, 모든 수정 전 승인을 받는 방식 대신 위험하거나 범위가 큰 작업에만 확인을 요청한다.
- 상단 색상 체계는 유지하면서 헤더·히어로·입력 카드·일정 카드의 너비, 간격, 글자 크기와 모바일 압축 비율을 정돈했다.
- 카카오의 넓은 장소 분류 때문에 같은 기본 아이콘이 반복되지 않도록, 일정 자동 생성 결과에 카페 `☕`, 맛집 `🍽️`, 전시 `🖼️`, 산책 `🌿` 아이콘을 적용한다.
- 지역 입력창에서 두 글자 이상 입력하면 카카오 장소 결과의 주소를 바탕으로 최대 5개의 지역 후보를 자동완성으로 보여준다.
- 장소 추가 검색에는 빈 검색어 안내, 검색 중 상태, 결과 개수 안내와 일정에 추가된 장소의 `추가됨` 상태를 표시한다.
- 검색 결과 카드를 일정 사이의 놓기 영역으로 드래그해 원하는 위치에 삽입할 수 있다. 기존 일정 카드도 드래그로 순서를 바꿀 수 있으며 시간표와 지도 순서는 자동으로 다시 계산된다.
- 일정을 모두 삭제한 경우에도 큰 빈 일정 드롭 영역을 표시해 검색 결과를 첫 장소로 끌어 놓을 수 있다.
- 검색 결과에서 드래그를 시작하면 위쪽 일정 영역으로 화면이 즉시 이동해, 검색 영역과 일정 영역이 한 화면에 보이지 않아도 원하는 위치에 놓을 수 있다.
- 자동 생성된 일정은 시작·종료 시간을 바꾸면 해당 시간 예산 안에 들어오도록 장소 개수를 즉시 다시 조정한다. 사용자가 직접 추가·삭제·드래그한 일정은 임의로 삭제하지 않는다.
- 일정 상단의 `동선 정리` 버튼을 누르면 현재 장소들을 더 가까운 방문 순서로 재배치하고 줄어든 예상 도보시간을 안내한다. 장소 추가 시 자동 팝업은 띄우지 않는다.
- 마우스뿐 아니라 모바일·태블릿의 터치와 펜 입력으로도 드래그할 수 있다. 손잡이를 누른 채 이동하면 현재 장소 미리보기와 활성 드롭 위치를 표시한다.

## 새 대화에서 이어가는 방법

새 Codex 작업을 열고 이 프로젝트 폴더를 선택한 뒤 다음처럼 요청하면 된다.

> `AGENTS.md`와 `docs/PROJECT_CONTEXT.md`를 읽고 하루여행 프로젝트를 이어서 작업해줘.

새 작업이 이 폴더와 연결되지 않았다면 Codex는 이 문서를 자동으로 볼 수 없으므로, 이 폴더를 작업 공간으로 열거나 문서를 첨부해야 한다.
