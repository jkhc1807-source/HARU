## 데이터 출처와 계산 방식

- 첫 화면의 성수동 장소는 초기 체험용 샘플 데이터다.

## 최근 결정 기록

- 지도에 `내 위치` 버튼을 추가했다. 사용자가 버튼을 누른 경우에만 브라우저 위치 권한을 요청하며, 허용 시 현재 위치로 지도를 이동하고 일정 마커와 구분되는 파란 마커를 표시한다. 위치 정보는 저장하지 않는다. 카카오맵 범위 밖의 잘못된 위치가 반환되면 빈 지도로 이동하지 않고 기기 위치 설정 확인을 안내한다.
- Sites 배포는 로컬 환경변수로 생성한 사전 빌드 압축 파일을 사용한다. 카카오 키가 필요한 소스 빌드를 배포 서버에서 다시 실행하지 않도록 저장 버전에 `archive`를 전달한다.
- 시간 선택 범위를 오전 7시부터 밤 12시까지로 제한했다. 최초에는 종료 시간을 비활성화하고, 시작 선택 후에는 해당 시간보다 뒤인 종료 시간만 30분 단위로 보여준다. 시작을 바꾸면 기존 종료 선택은 초기화한다.
- 브라우저마다 다르게 보이던 시간 입력을 시작·종료가 분리된 30분 단위 선택 UI로 교체했다. 오전·오후를 한글로 표시하고 잘못된 시간 범위는 선택 영역에서 즉시 강조한다.
- 일정 생성 결과와 시간·취향·지도 연결 오류를 생성 버튼 바로 아래에 표시한다. 1시간 미만 또는 시작 이후가 아닌 종료 시간, 빈 취향, 지도 미연결, 빈 검색 결과를 구분하고 생성 중 중복 실행을 막는다.
