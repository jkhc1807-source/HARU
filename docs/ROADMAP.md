## 결정 기록

- 사용자가 요청할 때만 현재 위치 권한을 받아 지도 중심과 파란 위치 마커를 갱신하며 위치는 저장하지 않는다. 한국 밖의 잘못된 좌표는 지도 이동 전에 차단한다.
- 시간은 오전 7시부터 밤 12시 사이에서 고르며 시작 선택 전에는 종료를 비활성화하고, 시작 이후의 종료 시간만 제공한다.
- 시작·종료 시간을 오전·오후가 표시되는 30분 단위 선택 UI로 제공하고 잘못된 범위를 즉시 강조한다.
- 일정 생성 버튼 가까이 로딩·성공·시간 오류·결과 없음 안내를 표시하고 생성 중 중복 실행을 막는다.
- SUIT 글꼴로 전체 인상을 가볍게 조정하고, 데스크톱 히어로 문구와 입력 카드 묶음을 화면 중앙에 정렬한다.
- 헤더 로고에 해와 짧은 여행 동선 심볼을 추가하되 기존 워드마크와 색상 체계는 유지한다.
- Sites와 Vercel의 배포 출력 형식이 다르므로 각각 `vinext build`와 표준 Next.js 빌드를 사용한다.
- 배포 플랫폼에는 `.env.local` 파일 대신 카카오 JavaScript 키 환경변수를 등록하고, 빌드 시 해당 값을 지도 설정 파일로 생성한다.
- 토이 프로젝트 원칙에 따라 무료 쿼터 안에서 운영한다.
- 현재 버전의 이동시간은 외부 경로 API 없이 추정한다.
- 로그인과 서버 데이터베이스는 여러 일정 저장 단계 전까지 도입하지 않는다.
- v20 종합 점검 결과와 후속 우선순위는 `docs/UX_AUDIT.md`에서 관리한다.
- 실제 일정 데이터가 포함되지 않는 공유 버튼은 제거하고, 공유 링크 단계에서 다시 구현한다.
